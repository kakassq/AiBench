# AiBench Reel · 品牌 / 社媒短片流水线

竖版优先（9:16），每格 2 秒，字幕不超过 4 个字。没人念旁白，节奏全靠切点和字标。

## 你只能用这套动效语言

| look id | 气质 | 适用 |
|---|---|---|
| `one-line` | 一笔画：一根线走完全片 | 字标起手、极简品牌 |
| `swiss-dynamic-type` | 瑞士排版：巨字、网格、单一强调色 | 卖点、判断句 |
| `terminal-crt` | 终端 CRT：扫描线、荧光绿、光标 | 倒数、系统感、科技感 |
| `halftone-dossier` | 半调案卷：纸感、网点、案卷标签 | 快剪、社媒 |
| `blueprint` | 蓝图：技术网格、等宽字体 | 参数、规格对比 |

## 流水线

1. **定钩子**：前 2 秒必须出现一个能记住的东西——字标、一个数字、或一句 4 字以内的话。
2. **三点卖点**：3 个卖点，每个占 4 拍（BPM 120 → 2 秒）。每点一句话 ≤4 汉字 + 一个视觉动作。
3. **定 look**：字标片头 → one-line；卖点快剪 → halftone 或 swiss；倒数 → crt。
4. **卡点**：切点一律落在整拍上。BPM 120 时 1 拍 = 15 帧，1 格 2 秒 = 60 帧 = 4 拍。
5. **落版**：最后一格只放字标 + 一句副标题，不要塞第三个信息。
6. **校验**：先出 still 看竖版安全区（左右留白 ≥ 8%），再出 mp4 听卡点。

## 硬约束（违反即视为失败）

- 竖版 1080×1920 时，标题字号不超过 0.13 × 宽度，否则中文会撞边。
- 字幕单行 ≤ 4 个汉字；这比横版严格得多，因为竖版可视宽度只有 1080。
- 每格严格 2 秒（60 帧 @30fps）或 4 拍；不要出现 1.5 秒这种非整拍长度。
- 30 fps，所有分镜帧数之和必须等于 `totalFrames`。
- 只用 `bg` / `fg` / `accent` 三色。
- 禁止 `Date.now()` / `Math.random()`；随机一律来自 `seed = hashText(brief)`。
- 结尾必须有落版帧，不能直接黑场结束。
